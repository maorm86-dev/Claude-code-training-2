# Claude Code Academy

אתר לימוד בעברית (RTL) ל־Claude Code, מרמת מתחילים ועד אוטומציה מתקדמת. HTML + CSS + JavaScript בלבד, בלי שלב build ובלי תלויות.

## הרצה

פתחו את `index.html` בדפדפן. אפשר גם שרת מקומי:

```bash
python3 -m http.server 8000   # ואז http://localhost:8000
```

ההתקדמות נשמרת ב־localStorage של הדפדפן (מפתח `cca.v1`). בעמוד **התקדמות** אפשר לייצא ולייבא גיבוי.

## מבנה

```
index.html          מסגרת הדף
css/style.css       עיצוב (ערכות בהיר וכהה, RTL)
js/core.js          מנוע: מצב, חזרה מרווחת, XP, תגים, חיפוש
js/views.js         תצוגות וניתוב
data/               *כל התוכן* — כאן עורכים כדי לעדכן
  meta.js           שם, גרסה, תאריך אימות, רמות
  lessons-1..4.js   השיעורים
  cards.js          כרטיסיות
  challenges.js     אתגרים
  games.js          משחקים
  cheats.js         מדריך מהיר
  changelog.js      יומן שינויים
```

## הוספת תוכן (בלי לגעת במנוע)

**שיעור חדש** — הוסיפו אובייקט ל־`COURSE.modules.push(...)` באחד מקבצי `lessons-*.js`:

```js
{
 id:'m22', level:3, order:6, icon:'🧪', title:'כותרת', minutes:12, verified:'2026-10-19',
 summary:'משפט או שניים.',
 goals:['מטרה 1','מטרה 2'],
 predict:{q:'שאלת ניחוש לפני הקריאה',a:'התשובה'},
 docs:[['skills','Skills']],                 // [נתיב תחת docsBase, שם]
 blocks:[
  {t:'h',x:'כותרת משנה'},
  {t:'p',x:'טקסט עם `קוד` ו־**הדגשה** ו־[קישור](https://example.com)'},
  {t:'list',x:['פריט','פריט'], ord:false},     // ord:true לרשימה ממוספרת
  {t:'steps',x:['צעד 1','צעד 2']},
  {t:'code',x:'claude --version'},
  {t:'callout',k:'tip',x:'טיפ'},               // k: tip | warn | note
  {t:'table',head:['א','ב'],rows:[['1','2']]}
 ],
 recap:['נקודה 1','נקודה 2'],
 quiz:[{q:'שאלה?',o:['נכון','שגוי','שגוי','שגוי'],a:0,w:'הסבר'}]   // a = אינדקס התשובה הנכונה; הסדר מעורבב אוטומטית
}
```

**כרטיסיה:** `['m22','שאלה','תשובה']` ב־`cards.js`. המזהה נגזר מנוסח השאלה, ושינוי הנוסח מאפס את ההתקדמות בה.

**אתגר:** אובייקט עם `id, l, m, t, min, g, s[], ok, x, r` ב־`challenges.js`.

**משחק:** שלושה סוגים ב־`games.js`: `match` (זוגות), `choice` (שאלות), `order` (סדר שלבים).

**מדריך מהיר:** סעיף `{t, rows:[[פקודה,הסבר]]}` ב־`cheats.js`.

אחרי כל עדכון: הוסיפו רשומה ל־`changelog.js`, ועדכנו `contentVersion` ו־`verifiedOn` ב־`meta.js`.

## כללי כתיבה בקבצי data

- מחרוזות עם גרשיים בודדים. אל תשתמשו בגרש ישר בתוך עברית; השתמשו ב־׳ (דק׳, פיצ׳ר) וב־«» או ״ לציטוט.
- קוד בתוך טקסט: `` `כך` ``. בלוק קוד (`t:'code'`) לא מעבד סימונים.
- שיעור עם 3 שאלות חידון מספיק. השאלות נכנסות אוטומטית למאגר התרגול.

## עדכון עם Claude Code

הריצו `claude` בתיקייה והדביקו:

```
קרא את CLAUDE.md. בדוק מול התיעוד הרשמי (https://code.claude.com/docs) מה השתנה ב-Claude Code
מאז verifiedOn ב-data/meta.js. עדכן רק את השיעורים, הכרטיסיות והמדריך המהיר הרלוונטיים,
הוסף רשומה ל-data/changelog.js, ועדכן contentVersion ו-verifiedOn.
בסוף הרץ node --check על כל קבצי ה-JS.
```

להוספת נושא חדש: «הוסף שיעור על X ברמה 3 לפי תבנית השיעורים הקיימים, עם 4 כרטיסיות ואתגר».

## פרסום

GitHub Pages: דחפו את התיקייה לריפו, והפעילו Pages מהענף הראשי. אין שלב build.

## עקרונות הלמידה שמובנים באתר

ניחוש לפני קריאה (pretesting), שליפה פעילה (חידונים, כרטיסיות), חזרה מרווחת (ליינטנר: 1, 3, 7, 16, 35 ימים), ערבוב נושאים (תרגול מעורב), למידה במעשה (אתגרים), והסבר במילים שלכם (רפלקציה בכל אתגר).
